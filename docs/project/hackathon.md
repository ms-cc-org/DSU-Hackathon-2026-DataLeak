# Hackathon essentials

Data to Harvest: AI for Agricultural Resilience, Delaware State University, October 17–18, 2026. Condensed from the organizer's student and mentor briefings; this describes the event, not additional HARVEST features to build.

## Required handoff

- Name one user, one realistic decision and when it is made.
- Present evidence checked on years not used to build the method, or explain honestly why that check is unavailable.
- Supply a working app/notebook/Python tool and reproducible run instructions in the team's public repository.
- Give an approximately five-minute pitch/live demo followed by three minutes of questions. Explain user, decision, evidence and verification.
- Include AI tools, their contributions and how their output was verified in the README. The team must be able to explain and change the code.
- Keep secrets out of Git; use ignored environment files.

**Submission deadline:** Sunday, October 18, 2026, noon Eastern. One submission per team through the organizer's [submission form](https://github.com/ms-cc-org/DSU-Hackathon/issues/new?template=submission.yml), including team/member details, repository URL and the exact full 40-character commit SHA. Later pushes are not part of that submitted version.

## Judging

| Criterion | Weight |
|---|---:|
| Problem definition and relevance | 20% |
| Data and evidence | 20% |
| Usability and working prototype | 15% |
| Demonstration and presentation | 15% |
| Technical implementation | 10% |
| Innovation | 10% |
| Collaboration | 10% |

Prioritize a complete user workflow and explain limitations. Data caveats and source credits are in the [data guide](../data/dataset.md); HARVEST's chosen scope is in [scope](scope.md).
